# ❤️ Heart Disease Prediction using Neural Networks

This project builds a **binary classification model** to predict the presence of **heart disease** using the **UCI Cleveland Heart Disease dataset** and a **Neural Network (Keras/TensorFlow)**.

---

## 📂 Dataset

- **Source:** UCI Machine Learning Repository  
- **File used:** `processed.cleveland.data`
- **Target variable:**
  - `0` → No heart disease
  - `1` → Heart disease present

---

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
